I created this repository with the objective of learning transformers in-depth. From zero to being able to deploy a seq2seq transformer in production, for Spanish to English translation.

Everything will be created from scratch, I'm planning to do:
- Corpus preparation
- Tokenization and Embeddings
- Encoder/Decoder Transformer
- Testing
- Deployment
- Monitoring

Also, it's very important to emphasize that I'm going to build this using no AI. This is just for the sake of learning.
